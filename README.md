### Chapter 1: Visual C# and the IDE

- Visual C# uses **Object-Oriented Programming (OOP)**.
- Objects contain **properties** (data) and **methods** (actions).
- Common controls include **Labels, Buttons, TextBoxes, PictureBoxes, and Timers**.
- Important Visual Studio windows are:
  - **Designer:** Creates the user interface.
  - **Solution Explorer:** Manages project files.
  - **Properties Window:** Changes control settings.
  - **Toolbox:** Provides controls.
- C# code is organized into **namespaces, classes, and methods**.
- GUI programs use **event-driven programming**, such as button-click events.
- Useful features include `MessageBox.Show()`, `this.Close()`, IntelliSense, and syntax error indicators.

### Chapter 2: Processing Data

- **TextBoxes** accept user input as strings.
- Variables store data and use types such as `string`, `int`, `double`, and `decimal`.
- C# supports arithmetic operators: `+`, `-`, `*`, `/`, and `%`.
- Text must be converted to numbers using methods such as `int.Parse()` and `double.Parse()`.
